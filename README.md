## Overview

This repository houses the personal portfolio website of **Bayu Sedana**. Designed with a focus on visual elegance, speed, and strict craftsmanship standards, the site presents a comprehensive look into professional software development, end-to-end data analytics pipelines, corporate keynote training, and verified technical credentials.

### Key Highlights
- **Zero Heavy Framework Overhead**: Built with pure semantic HTML5, modern vanilla CSS (CSS Grid, Flexbox, Custom Properties), and modular ES6 JavaScript.
- **Bilingual Experience (ID / EN)**: Instant language switching with complete dictionary parity and persistent localStorage preferences.
- **Adaptive Dark / Light Modes**: Tailored high-contrast color palettes ensuring full WCAG readability in any lighting condition.
- **Partitioned Career Architecture**: Side-to-side dual column view distinguishing between In-House Full-Time roles and Independent Consulting / Freelance practice.
- **Interactive Project Catalog**: Multi-tag filtering system (Google Colab, Web App & Dashboard, Tableau, Fintech & Indofun, AI Workshop) with full lightbox previews.
- **Documentation & Keynote Gallery**: Curated photo albums from executive workshops and university guest lectures (Bank Indonesia, TNI, BINUS, Universitas Terbuka, UNTAG).

## Getting Started

### Local Development

No package installation or compilation steps are required. You can serve the static files using any local HTTP server:

Using Python:
```bash
python3 -m http.server 8080
```

Using Node.js:
```bash
npx serve . -p 8080
```

Open your browser and navigate to:
```text
http://localhost:8080
```
